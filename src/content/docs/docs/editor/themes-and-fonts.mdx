Ported themes keep the source palette's hues but always use Tori's own
status and agent colors, never repainted by the port, so working, needs you
and done look the same in every theme. Switch in Settings > Appearance, or
with the toggle in the top bar, which starts from your system's light or
dark preference the first time you open Tori. File icons take their hues
from the theme too.

## Pick a theme

Open Settings (the gear in the title bar) > **Appearance** > **Theme**. The picker has **Dark** and
**Light** tabs, and themes are grouped as **Bundled** and **From
~/.config/tori/packs/themes**. The theme applies as you click it. **Add a
theme** below the picker lists the themes in the [catalog](/packs/?kind=themes).

The sun and moon button in the top bar switches between your light and dark
choice. The first time you open Tori it follows your system's appearance.

## Make your own theme

A theme is one JSON file of colours. Copy a bundled one as a starting point,
give it its own `id` and file name, change the colours, and save it in
`~/.config/tori/packs/themes/`. Tori watches the folder, so the theme appears in the picker without a restart, and edits to the
file apply as you save.

```json
{
  "schemaVersion": 1,
  "id": "hooli",
  "label": "Hooli",
  "appearance": "dark",
  "colors": {
    "canvas": "#15171c",
    "card": "#1b1e25",
    "text": "#e4e8f0",
    "accent": "#4a9eff"
  }
}
```

The file holds flat hex colours only (`#rgb`, `#rrggbb` or `#rrggbbaa`), one
per role: surfaces (`canvas`, `card`, `head`, `input`, `hover`), lines, text,
the accent, status colours, diff and diagnostic colours, and the syntax
colours. Everything else, washes, shadows and the names the interface uses, is
worked out from those, so a theme file can never contain anything but colours.

Before a theme is used, Tori checks it is legible: text has to contrast with
the surfaces behind it. A theme that fails is not offered, and if it is already
selected the window keeps the theme it had and toasts say what failed, naming
the colours. Fix the file and save it again.

## Fonts

Settings > Appearance > **Typography** sets the **UI font family** and size,
the **Editor font family** and size, the **Terminal font family** and size, and
the **Line height**, independently. Any font installed on your Mac works. The bundled terminal font is
JetBrains Mono Nerd Font, so prompt glyphs (powerline separators, devicons)
render correctly without you needing to install a patched font yourself.

Zoom (`Cmd+=` / `Cmd+-` / `Cmd+0`) scales everything, chrome, editor and
terminal together, on top of whatever font sizes you have set, and is kept
separate from your settings file so a quick zoom in and out never touches it.
