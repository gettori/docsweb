title: Using the phone app
description: What the screens show, once you are paired.
---

## Projects and Topics

A space switcher along the bottom, a search box that covers projects,
worktrees and live sessions, and two views: **Projects**, each row showing a
status rollup and session count, or **Topics**, showing each Topic's
members. Tapping a project opens its worktree cards, each with ahead/behind
marks, pull request status, and issue chips, the same information the
desktop sidebar shows.

## A worktree

Branch name, diff counts, sync status, a **New** button to start a fresh
chat there, and the session list split into what is running now and history.

## Chat

The same message rendering the desktop uses, paged history, a model and mode
picker (hidden for autopilot's own chat), and a composer to steer or send.
Whatever a session is waiting on, a structured question, a permission
request, or an approval, shows as a card with the same answers you would
have on the desktop: buttons, or free text.

## Autopilot

A scene that matches the desktop Cockpit's own time-of-day art, an on and
off switch, decision cards for anything waiting on you, the list of crew
currently running, and a log. A composer at the bottom messages autopilot
directly.

## Settings

A bottom sheet: your connection (the Mac's address, this phone's saved name,
and Disconnect, which forgets this phone's own credential, the paired device
still has to be revoked from the Mac separately to remove it there too),
dark or light theme, and a switch for whether the autopilot button shows in
the bottom bar at all.

## Platform

Android is out now, an APK on the Releases page, not through the Play Store;
see [Install](/docs/install) for how to get it. An iOS app is planned.
